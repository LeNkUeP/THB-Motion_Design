# THB-Motion_Design

This repo consists of submission task for the university module "Motion Design". Animations based on current worldwide news were created weakly. Programs like Affinity Designer or Adobe After Effects were used. Main purpose of the module was to understand how to work with the said software, how to create animation, design logos and learn the basics about motion design.

As a topic, news related to the ucraine conflict were chosen. All animation were uploaded to YouTube. The channel can be found here: www.youtube.com/@die3Brocken.

## News animation

The main task was to create and upload weekly animation related to a current event in the world/news. My topic was the ucraine conflict.
